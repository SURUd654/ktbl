# ことバトル（ktbl）🐝

16bitピクセルアート風の言葉対戦Webゲーム（PWA対応・完全フロントエンド完結）です。  
OpenAI互換API（OpenRouter / OpenAI / ローカルProxy 等）とブラウザから直接通信して遊べます。

## 主な特徴
- **完全フロントエンド完結**：サーバー不要。画像アセットはすべて `index.html` 内に Base64 埋め込み済み。
- **PWA対応（全画面プレイ）**：スマホのホーム画面に追加すると、可愛いミツバチアイコン付きのネイティブアプリ風全画面で遊べます。
- **3種類のピクセル着せ替えテーマ**：はちみつ広場 / すみれの星空 / ミントのゲーム機
- **多彩なルール＆ジャンル**：
  - VS AIモード（トリックスター / カオス / 王道）＆ 一人二役モード
  - 文字数制限（10文字 / 20文字 / 40文字 / 制限なし）
  - お題ガチャ（おまかせ / 感情・感覚 / 強さ・スペック / シチュエーション大喜利 / **書き出し小説**）＋自由入力
- **個性派ジャッジ＆名勝負アーカイブ**：6名のプリセット審査員＋カスタム審査員自作、別ジャッジでのリベンジ再判定、お気に入り保存機能。

## プライバシーとAPIキーについて
API Key・プロキシURL・設定・名勝負アーカイブはすべてお使いのブラウザの `localStorage` のみに保存されます。リポジトリ内には一切の秘密情報を含んでいません。
